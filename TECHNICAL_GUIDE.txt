   2. TEACHER

      • Can create and manage events
      • Gets teacher dashboard after login

   3. ADMIN
      • Cannot signup (hardcoded account only)
      • Email: admin2432@gmail.com
      • Password: Oxct@123456c
      • Has full system control


B. HOW SIGNUP WORKS:

   STEP 1: User clicks "Register" button
      → JavaScript opens the signup modal (popup)

   STEP 2: User selects role (Student or Teacher)
      → JavaScript shows/hides teacher key field based on selection
      → If Teacher selected: Key field appears
      → If Student selected: Key field hidden

   STEP 3: User fills in details
      → Name, Email, Password, Confirm Password
      → (Teacher also enters access key: 5577)

   STEP 4: User clicks "Register" button
      → JavaScript validates all fields:
         ✓ Checks if passwords match
         ✓ Checks if email is valid
         ✓ For teachers: Checks if key = "5577"
         ✓ Checks if email already exists

   STEP 5: If validation passes
      → JavaScript creates new user object:
         {
           id: 4,
           name: "John Doe",
           email: "john@example.com",
           password: "password123",
           role: "student",
           events: []
         }
      → Saves to users array in memory
      → Auto-logs in the user
      → Redirects to appropriate dashboard


C. HOW LOGIN WORKS:

   STEP 1: User clicks "Login" button
      → JavaScript opens login modal

   STEP 2: User selects role (Student, Teacher, or Admin)
      → JavaScript shows/hides teacher key field
      → Admin tab: No key field
      → Teacher tab: Key field appears
      → Student tab: No key field

   STEP 3: User enters credentials
      → Email and Password
      → (Teacher also enters access key)

   STEP 4: User clicks "Login" button
      → JavaScript checks credentials:
      
      FOR ADMIN:
         ✓ Checks if email = "admin2432@gmail.com"
         ✓ Checks if password = "Oxct@123456c"
         ✓ If match: Login successful
      
      FOR TEACHER:
         ✓ Checks if access key = "5577"
         ✓ Finds user with matching email and password
         ✓ Checks if user's role = "teacher"
         ✓ If all match: Login successful
      
      FOR STUDENT:
         ✓ Finds user with matching email and password
         ✓ Checks if user's role = "student"
         ✓ If match: Login successful

   STEP 5: After successful login
      → JavaScript saves user info to localStorage
      → Updates navigation bar (shows username and logout)
      → Redirects to appropriate dashboard


D. HOW WE REMEMBER LOGGED-IN USERS:

   We use "localStorage" - a browser feature that saves data:

   When user logs in:
      localStorage.setItem('currentUser', JSON.stringify(userInfo));
      ↑ This saves user info even after closing browser

   When page loads:
      const user = localStorage.getItem('currentUser');
      ↑ This retrieves saved user info

   When user logs out:
      localStorage.removeItem('currentUser');
      ↑ This deletes saved user info

6. DESIGN SYSTEM - HOW WE MADE IT LOOK GOOD
================================================================================

A. COLOR SCHEME:

   We use CSS Variables (like reusable colors):

   --accent-primary: #3b82f6;      ← Main blue color
   --accent-secondary: #8b5cf6;    ← Purple color
   --accent-tertiary: #06b6d4;     ← Cyan color
   --bg-primary: #ffffff;          ← White background
   --text-primary: #1e293b;        ← Dark text

   Why variables? 
   → Change one value, updates everywhere!


B. GRADIENTS:

   Instead of flat colors, we use gradients (color transitions):

   --gradient-primary: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
                       ↑ Starts with blue-purple → Ends with purple

   Used for:
   • Buttons (makes them look modern)
   • Headers (adds visual interest)
   • Role tabs (highlights active selection)


C. SHADOWS:

   We add shadows to create depth:

   box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
               ↑ ↑   ↑   ↑
               │ │   │   └─ Transparency (10%)
               │ │   └───── Blur amount (6px)
               │ └───────── Vertical offset (4px down)
               └─────────── Horizontal offset (0px)

   Makes cards "float" above the page!


D. ANIMATIONS:

   We use CSS animations for smooth effects:

   @keyframes fadeInUp {
       from {
           opacity: 0;              ← Starts invisible
           transform: translateY(30px);  ← Starts 30px down
       }
       to {
           opacity: 1;              ← Ends visible
           transform: translateY(0);     ← Ends at normal position
       }
   }

   Result: Elements smoothly fade in and slide up!


E. RESPONSIVE DESIGN:

   We use "media queries" to adapt to different screen sizes:

   @media (max-width: 768px) {
       /* Styles for tablets and phones */
       .navbar {
           padding: 1rem;  ← Less padding on mobile
       }
       .events-container {
           grid-template-columns: 1fr;  ← Single column on mobile
       }
   }

   Result: Website looks good on phone, tablet, and desktop!

7. KEY CONCEPTS - IMPORTANT THINGS TO REMEMBER
================================================================================

CONCEPT 1: THE DOM (Document Object Model)
   ┌────────────────────────────────────────────────────────┐
   │ What is it?                                            │
   │ The DOM is how JavaScript sees your HTML               │
   │                                                         │
   │ HTML:                                                   │
   │ <div id="myDiv">Hello</div>                            │
   │                                                         │
   │ JavaScript can access it:                              │
   │ const div = document.getElementById('myDiv');          │
   │ div.textContent = 'Goodbye';  ← Changes text           │
   │                                                         │
   │ Think of it as: JavaScript's way to control HTML       │
   └────────────────────────────────────────────────────────┘


CONCEPT 2: EVENT LISTENERS
   ┌────────────────────────────────────────────────────────┐
   │ What is it?                                            │
   │ Code that "listens" for user actions                   │
   │                                                         │
   │ Example:                                                │
   │ button.addEventListener('click', function() {          │
   │     alert('You clicked me!');                          │
   │ });                                                     │
   │                                                         │
   │ Common events:                                          │
   │ • 'click' - When user clicks                           │
   │ • 'submit' - When form is submitted                    │
   │ • 'change' - When input value changes                  │
   │                                                         │
   │ Think of it as: Setting up a "trap" to catch actions   │
   └────────────────────────────────────────────────────────┘


CONCEPT 3: FUNCTIONS
   ┌────────────────────────────────────────────────────────┐
   │ What is it?                                            │
   │ Reusable blocks of code                                │
   │                                                         │
   │ Example:                                                │
   │ function login(email, password) {                      │
   │     // Check credentials                               │
   │     // Return true or false                            │
   │ }                                                       │
   │                                                         │
   │ Use it:                                                 │
   │ const success = login('user@email.com', 'pass123');    │
   │                                                         │
   │ Think of it as: A recipe you can use multiple times    │
   └────────────────────────────────────────────────────────┘


CONCEPT 4: OBJECTS
   ┌────────────────────────────────────────────────────────┐
   │ What is it?                                            │
   │ A way to group related data together                   │
   │                                                         │
   │ Example:                                                │
   │ const user = {                                          │
   │     name: 'John Doe',                                  │
   │     email: 'john@example.com',                         │
   │     role: 'student'                                    │
   │ };                                                      │
   │                                                         │
   │ Access data:                                            │
   │ console.log(user.name);  ← Prints "John Doe"           │
   │                                                         │
   │ Think of it as: A container with labeled compartments  │
   └────────────────────────────────────────────────────────┘


CONCEPT 5: ARRAYS
   ┌────────────────────────────────────────────────────────┐
   │ What is it?                                            │
   │ A list of items                                        │
   │                                                         │
   │ Example:                                                │
   │ const users = [                                         │
   │     { name: 'John', role: 'student' },                 │
   │     { name: 'Jane', role: 'teacher' },                 │
   │     { name: 'Admin', role: 'admin' }                   │
   │ ];                                                      │
   │                                                         │
   │ Access items:                                           │
   │ console.log(users[0].name);  ← Prints "John"           │
   │                                                         │
   │ Think of it as: A numbered list of things              │
   └────────────────────────────────────────────────────────┘


CONCEPT 6: CONDITIONAL STATEMENTS
   ┌────────────────────────────────────────────────────────┐
   │ What is it?                                            │
   │ Making decisions in code                               │
   │                                                         │
   │ Example:                                                │
   │ if (role === 'admin') {                                │
   │     console.log('Welcome Admin!');                     │
   │ } else if (role === 'teacher') {                       │
   │     console.log('Welcome Teacher!');                   │
   │ } else {                                                │
   │     console.log('Welcome Student!');                   │
   │ }                                                       │
   │                                                         │
   │ Think of it as: A flowchart with different paths       │
   └────────────────────────────────────────────────────────┘

10. TROUBLESHOOTING - COMMON ISSUES AND FIXES
================================================================================

PROBLEM 1: "Button doesn't work when clicked"
   ✓ Check: Is JavaScript file loaded?
   ✓ Check: Is event listener attached?
   ✓ Check: Are there any console errors? (Press F12 → Console tab)
   ✓ Fix: Make sure script tag is at bottom of HTML

PROBLEM 2: "Styles not showing up"
   ✓ Check: Is CSS file linked correctly in HTML?
   ✓ Check: Is file path correct? (styles/main.css)
   ✓ Check: Clear browser cache (Ctrl + Shift + R)
   ✓ Fix: Verify <link> tag in <head> section

PROBLEM 3: "Login not working"
   ✓ Check: Are credentials correct?
   ✓ Check: Is role selected?
   ✓ Check: For teacher: Is access key "5577"?
   ✓ Check: Console for error messages
   ✓ Fix: Verify auth.js is loaded

PROBLEM 4: "User stays logged in after closing browser"
   ✓ This is NORMAL - we use localStorage
   ✓ To logout: Click "Logout" button
   ✓ To clear manually: F12 → Application → Local Storage → Clear

PROBLEM 5: "Modal won't close"
   ✓ Check: Is close button (X) clickable?
   ✓ Check: Is event listener attached to close button?
   ✓ Fix: Click outside modal or press Escape key

11. IMPORTANT CODE SNIPPETS TO REMEMBER

A. HOW TO SELECT AN ELEMENT:
   const element = document.getElementById('myId');
   const element = document.querySelector('.myClass');
   const elements = document.querySelectorAll('.myClass');

B. HOW TO CHANGE TEXT:
   element.textContent = 'New text';

   element.style.color = 'blue';
   element.style.display = 'none';  // Hide

   element.classList.add('active');
   element.classList.remove('active');
   element.classList.toggle('active');

E. HOW TO LISTEN FOR CLICKS:
   element.addEventListener('click', function() {
       // Code runs when clicked
   });

F. HOW TO PREVENT DEFAULT BEHAVIOR:
   form.addEventListener('submit', function(e) {
       e.preventDefault(); // Stops form from submitting normally
   });

G. HOW TO SAVE TO LOCALSTORAGE:
   localStorage.setItem('key', 'value');
   const value = localStorage.getItem('key');
   localStorage.removeItem('key');

H. HOW TO SHOW ALERT:
   alert('This is a message');
   confirm('Are you sure?'); // Returns true/false
